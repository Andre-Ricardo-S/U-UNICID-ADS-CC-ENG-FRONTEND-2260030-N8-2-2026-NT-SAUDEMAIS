Preços do Railway: página oficial de preços, docs.railway.com/pricing/plans, consultada em 16/11/2026. Os valores são em dólar e podem mudar.

✅ Nossa escolha: Railway

  • Publica sozinho: a cada commit no GitHub, o Railway atualiza o site em poucos minutos.
  • HTTPS e endereço prontos: o site já sai com cadeado e um domínio .up.railway.app, sem custo extra.
  • Pensando no futuro: hoje os pedidos ficam só no localStorage de cada aparelho. Para o voluntário receber os pedidos de verdade, o projeto vai precisar de um back-end, e o Railway já roda servidores. O GitHub Pages não roda.
  • Equipe já conhecia: o Railway já tinha sido usado no MVP.
