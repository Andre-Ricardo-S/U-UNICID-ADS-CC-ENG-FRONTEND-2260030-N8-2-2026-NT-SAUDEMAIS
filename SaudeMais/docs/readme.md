# Contexto do projeto SaudeMais

## Objetivo
Portal academico de informacao e apoio relacionado a saude publica.

## Stack observada
- HTML5 nas paginas existentes.
- CSS3 em `css/styles.css` e em blocos `<style>` nas paginas.
- JavaScript em blocos `<script>` inline; nao ha arquivos `.js` proprios no projeto atual.
- Recurso externo atualmente usado: widget VLibras.

## Paginas existentes
- `index.html`
- `agendar.html`
- `configuracoes.html`
- `contato.html`
- `emergencia.html`
- `perfil.html`
- `prevencao.html`
- `sobre-nos.html`
- `sus.html`
- `unidades.html`

## Limites
- Idioma da interface: portugues do Brasil (`pt-BR`).
- Identidade visual observada: azul, branco e cinza.
- Nao incluir novas paginas, modulos ou dependencias sem confirmacao.
- Nao registrar nomes, dados pessoais, tokens ou identificadores privados neste plano.
